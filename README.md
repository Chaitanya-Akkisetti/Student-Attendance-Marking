# Student Attendance System

A simple desktop-based **Student Attendance System** developed using
**Python** and **Tkinter**. The application displays student roll
numbers and date-wise attendance checkboxes, calculates the number of
students present on each date, and saves attendance data in a local text
file.

## Features

-   **Graphical user interface:** Built with Python's Tkinter library.
-   **Student list:** Displays 25 students with generated roll numbers.
-   **Date-wise attendance:** Provides checkboxes for 17 dates in March
    2026.
-   **Daily present count:** Shows the number of students marked present
    for each date.
-   **Save attendance:** Stores checkbox values in `check.txt`.
-   **Load saved attendance:** Loads previously saved values when the
    application starts, if `check.txt` exists.

## Technologies Used

-   **Programming language:** Python 3
-   **GUI library:** Tkinter
-   **Data storage:** Plain-text file (`check.txt`)

## Requirements

-   Python 3 installed on your computer.
-   Tkinter, which is included with most standard Python installations.

To check your Python installation, run:

``` bash
python --version
```

On some systems, you may need to use `python3` instead of `python`.

## How to Run

1.  Download or clone this project.

2.  Open a terminal or Command Prompt in the project folder.

3.  Run the following command:

    ``` bash
    python mini_project.py
    ```

    If required, use:

    ``` bash
    python3 mini_project.py
    ```

4.  The Student Attendance System window will open.

5.  Tick the checkbox for each student who is present on a particular
    date.

6.  Check the **Present** count below each date column.

7.  Click **Save** to write the attendance values to `check.txt`.

## How It Works

1.  The application creates a Tkinter window titled **Student Attendance
    System**.
2.  It displays 25 student roll numbers and 17 date columns.
3.  Each checkbox represents one student's attendance on one date.
4.  When a checkbox is changed, the application updates the daily
    present count and saves the current checkbox values.
5.  When the application starts, it attempts to load the values from
    `check.txt`.
6.  The Save button saves the values and closes the application.

## Data Storage

Attendance is stored in `check.txt` as one integer per line:

-   `1` means the student is marked present.
-   `0` means the student is not marked present.

The values are stored in the order used by the application's
student-and-date grid. Keep `check.txt` in the same working directory
when reopening the project so saved attendance can be loaded.

## Limitations

-   The student count is fixed at 25.
-   The date count is fixed at 17, with date headings for March 2026.
-   Student details and dates cannot currently be edited through the
    interface.
-   Attendance is stored in a plain-text file rather than a database.
-   The application does not currently calculate attendance percentages
    or generate reports.
